Reproducibility notes

  • Four leave-one-dataset-out folds are used when all corpora are present.
  • Multi-layer WavLM features are cached once using a stable content signature, so an unchanged dataset is not needlessly re-encoded.
  • Source training uses corpus-class balancing and source-only cross-corpus feature mixup; target utterances are never used for adaptation.
  • Temperature scaling and conformal thresholds are fitted only on source validation data.
  • Nominal conformal guarantees require exchangeability; target-corpus coverage is therefore reported empirically rather than claimed as guaranteed.
