## Upload through the GitHub web interface

1. Sign in to GitHub.
2. Click **New repository**.
3. Repository name: **AffectBridge-UQ**.
4. Set visibility to **Public** if the chapter will cite a public code URL.
5. Do **not** add a new README, `.gitignore`, or license because this package already contains them.
6. Create the empty repository.
7. Use **Add file → Upload files**.
8. Upload the **contents inside** the `AffectBridge-UQ_GitHub_Ready` folder, preserving folders.
9. Commit with a message such as `Initial AffectBridge-UQ v2.1 research release`.
10. On the right sidebar, add the repository description and topics listed above.
11. Open `CITATION.cff` on GitHub and confirm the **Cite this repository** panel appears.

The intended final URL is:

`https://github.com/Mind-Twister-Wizard/AffectBridge-UQ`
